# Repository workflow

- Write README files, documentation, and all source and configuration comments in natural English.
- Keep commits local. The repository owner handles pushes. Change remote refs only when the user explicitly requests it.
- Use the repository owner's configured Git identity.
- Write commit messages that describe the change. Leave out provider references, automated attribution, and attribution trailers.

- Keep this student project straightforward. Add abstractions and dependencies only when an implemented feature needs them.
- Keep README files and documentation concise.
